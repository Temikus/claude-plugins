# Temikus's Claude Code plugins

A personal marketplace of Claude Code plugins.

## Install

Add this marketplace to Claude Code:

```
/plugin marketplace add Temikus/claude-plugins
```

Then install any plugin from the list below:

```
/plugin install <plugin-name>@temikus
```

## Plugins

| Plugin | Description |
| --- | --- |
| [`claude-watchdog`](https://github.com/Temikus/claude-watchdog) | Auto-runs a critical session post-mortem when Claude Code stops. |

## Updating

```
/plugin marketplace update temikus
```

## Removing

```
/plugin marketplace remove temikus
```
